# wolf_dl

늑대닷컴(만화) 다운로더 — SJVA/flaskfarm 플러그인.

## 저장 폴더 이름

- 작품 폴더 `{다운로드 경로}/{종류}/{작품명}/`, 회차 폴더 `{번호 4자리}_{회차 제목}` (압축 사용 시 같은 이름의 `.zip`).
- 윈도우·SMB 에서 못 쓰는 글자 `\ / : * ? " < > |` 는 모양이 같은 전각 문자 `＼ ／ ： ＊ ？ ＂ ＜ ＞ ｜` 로 바꿔 저장합니다 (0.6.2 부터, 이전에는 `_`).
- 0.6.1 이하에서 `_` 로 저장된 작품·회차 폴더와 압축 파일(`.zip`/`.cbz`)은 자동 실행·작품 처리·수동 다운로드 시작 시 새 이름으로 자동으로 옮겨지고, DB 의 저장 경로도 함께 갱신됩니다.
  - 새 이름 폴더가 이미 있으면 내용을 합치며, 같은 이름의 파일·폴더는 덮어쓰지 않고 로그에 `[rename]` 경고만 남깁니다.
  - 제목에 원래 `_` 가 들어간 경우는 건드리지 않습니다.
