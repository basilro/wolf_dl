늑대닷컴 다운로더 — 사용법

스케줄러가 돌 때마다 설정에 적힌 작품들을 순회:

  1. 회차 목록 ({base_url}/list?toon={workId}) HTML 파싱 — 페이지네이션 순회로 전체 회차 수집
    • 회차 목록 + 작품 메타(제목/장르/썸네일/줄거리) 추출
    • info.xml / cover.jpg 자동 생성 (없으면)
  2. 미수신 회차 중 최신 N개 (max_per_run) 만 다운로드 (0=전체)
  3. 회차 뷰어 ({base_url}/view?toon={workId}&num={num}) 의 본문 이미지(img[data-src]) 다운로드
  4. 회차당 이미지 → {경로}/manhwa/{작품}/{NNNN_회차}/{001.jpg ...}
  5. DB(wolf_dl_item) 에 회차별 이력 기록 — 같은 회차 재다운로드 안 함

옵션

  • 회차 폴더 ZIP 압축
  • 다운 완료 시 Discord/Slack 웹훅 알림 (자동·수동 공통)
  • 도메인 / 쿠키 만료 시 알림 웹훅 (인증 탭)
  • 도메인 자동 갱신 — 호스트 끝 숫자 +1~+5 증가 후, 실패 시 텔레그램 공지 채널 파싱

핵심 특징

  • 무로그인 — 별도 회원가입/쿠키 입력 없이 작동. 일부 환경에서만 인증 탭의 쿠키 입력 필요.
  • 제목 검색 — "수동 다운로드" 메뉴에서 제목으로 검색 → 결과에서 즉시 다운로드 또는 자동 목록에 추가.
  • 도메인 로테이션 대응 — 늑대닷컴은 도메인을 자주 바꿈. 공식 텔레그램 공개 채널(t.me/s/wfwf_com)에서 최신 주소를 자동 추출.

문제 해결

  • "접속 실패" 알림이 오면 → 인증 탭의 늑대닷컴 도메인 을 공지 채널에서 확인 후 수동 갱신(또는 "도메인 자동 갱신").
  • 다운로드 중 차단(blocked) 메시지가 자주 뜨면 → 인증 탭에 브라우저 쿠키 입력 또는 프록시/FlareSolverr 설정.
  • 이력 초기화는 일반 탭의 "이력 초기화" 버튼으로. 작품 삭제는 목록 textarea 에서 줄 제거.
